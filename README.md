# Медиакоми — угадай цену квартиры в Коми

Мобильная веб-игра по данным объявлений Авито о квартирах Республики Коми: 10 раундов, угадывание цены бегунком, баллы за точность и итоговый «портрет» игрока (Жадный студент / Адекватный квартирант / Транжира).

## Запуск локально

Игра — статические файлы, достаточно любого сервера:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте файлы проекта:

   ```bash
   git init
   git add .
   git commit -m "Медиакоми: игра-угадайка цен на квартиры"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/mediakomi.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
3. Через минуту игра будет доступна по адресу `https://<ваш-логин>.github.io/mediakomi/`.

## Обновление данных

Данные генерируются скриптом из CSV с объявлениями:

```bash
pip install Pillow
python3 -I scripts/prepare_data.py
```

Скрипт скачивает до 3 фото на лот, сжимает их в WebP (≤800px, ~75% качества) и пересобирает `data.js`.

## Структура

- `index.html`, `style.css`, `app.js` — приложение (ванильный JS, без зависимостей)
- `data.js` — пул лотов (генерируется скриптом)
- `assets/img/` — сжатые фото
- `scripts/prepare_data.py` — подготовка данных

## Балльная система

Ошибка относительно реальной цены: ≤5% → 100 баллов, ≤10% → 80, ≤15% → 60, ≤25% → 40, ≤40% → 20, иначе 0. Максимум за игру — 1000.
